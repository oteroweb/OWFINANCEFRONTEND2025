D-009 · un solo selector, barra teñida que colapsa con el scroll
lockapp.owfinance.com/user/home

El modo ya no es global: cada contabilidad guarda el suyo, así que aparece como subtítulo de cada opción en vez de como un segundo selector. La barra colapsa con el primer scroll hasta quedar una línea de color — tocarla la expande, porque si no no habría forma de cambiar de contabilidad sin volver arriba. Scrolleá el contenido para verlo. Ojo: el header, el balance y los cántaros de este documento son de relleno, solo para ver hasta dónde llega el color — el costo real de altura de sumar la barra se juzga en ui_kits/lite-desktop/index.html, donde vive sobre el header de verdad.
